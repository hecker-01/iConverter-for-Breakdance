Converts Breakdance Icon Library uploads to clean, black path-only SVGs.

== Description ==

iConverter converts Breakdance Icon Library uploads to solid-black,
path-only SVGs in the browser before the upload is sent.

== Installation ==

1. Upload the plugin ZIP through the WordPress Plugins screen.
2. Activate iConverter for Breakdance.
3. Upload icons through Breakdance as usual.
